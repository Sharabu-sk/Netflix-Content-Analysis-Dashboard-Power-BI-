Project Charter
Netflix Content Analysis Dashboard (Power BI)
1. Project Title

Netflix Content Analysis Dashboard

2. Project Purpose

The purpose of this project is to design and deliver an interactive Power BI dashboard that analyzes Netflix’s publicly available content catalog to uncover trends in content distribution, genre dominance, regional availability, ratings, and release patterns.

The dashboard is intended to demonstrate the ability to transform raw data into actionable insights that support content strategy, portfolio evaluation, and high-level decision-making.

3. Problem Statement

Streaming platforms manage extensive and diverse content libraries. Without a centralized, interactive analytical view, stakeholders face challenges in quickly understanding:

The balance between movies and TV shows

Regional concentration of content

Genre and rating dominance

Historical growth trends in content releases

Static reports or spreadsheet-based analysis limit insight discovery and do not support efficient exploratory analysis.

4. Project Objectives

Build an interactive Power BI dashboard using Netflix content metadata

Analyze content trends across time, geography, genre, and ratings

Enable self-service filtering by year, country, and content type

Demonstrate data cleaning, modeling, and visualization best practices

Present insights in a clear, executive-friendly format

5. Target Audience

Primary Audience

Hiring managers (Data Analyst / BI / Analytics roles)

Business stakeholders evaluating content portfolios

Portfolio reviewers and interview panels

Secondary Audience

Product managers

Content strategy analysts

Media and entertainment analysts

6. Existing Solutions & Current State
Existing Approaches

Manual spreadsheet analysis

Static charts with limited interactivity

Isolated visualizations without integrated insights

Limitations

No centralized dashboard view

Limited ability to filter or drill down

Time-consuming insight generation

Poor storytelling and scalability

7. Proposed Solution

Develop a Power BI dashboard that provides:

KPI-level summaries of total content

Breakdown of Movies vs TV Shows

Geographic visualization of content availability

Genre and ratings distribution

Time-based trends in content releases

Interactive slicers for exploratory analysis

8. Project Scope
In Scope

Data ingestion from Kaggle dataset

Data cleaning and transformation using Power Query

Data modeling and calculated fields

Dashboard design and visualization

Insight identification and documentation

Out of Scope

Predictive or forecasting models

Viewer behavior or engagement analysis

Revenue or subscription analytics

Real-time or API-based data refresh

Competitive platform comparison

9. High-Level Project Roadmap
Phase	Description

Data Modeling	Create relationships and calculated fields
Visualization Design	Build charts, maps, and slicers
Insight Development	Identify trends and patterns

12. Assumptions & Constraints
Assumptions

Dataset accurately represents Netflix’s historical catalog

Metadata fields are consistently labeled

Constraints

Limited to content metadata only

Public dataset may not reflect current Netflix catalog
