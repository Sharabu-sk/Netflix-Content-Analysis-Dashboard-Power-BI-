# Netflix-Content-Analysis-Dashboard-Power-BI-
This is a quick dashboard project built to explore Netflix’s content library using data from Kaggle.
## Dataset
- Source: [Netflix Movies and TV Shows – Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows)
- File: `netflix_titles.csv`

## Key Features
- Total number of titles available on Netflix
- Breakdown of Movies vs. TV Shows
- Top 10 countries by title count
- Ratings distribution (TV-MA, PG, etc.)
- Content release trends over time
- Genre distribution visualized via treemap
- Interactive map showing content by country and type
- Slicers for filtering by year, country, and type

## Tools Used
- Power BI Desktop
- Power Query Editor (for cleaning)
- Visuals: Card, Donut, Column Chart, Line Chart, Treemap, Map, Slicer

## Observations
- The U.S. and India lead in total content on the platform
- TV-MA is the most common rating
- There has been a sharp increase in content releases post-2015
- Drama and Comedy are the most frequent genres

## About This Project
This dashboard was completed in a single evening as part of a personal goal to build faster, clearer data stories. It’s intended as a portfolio piece to demonstrate practical Power BI skills using a publicly available dataset.
